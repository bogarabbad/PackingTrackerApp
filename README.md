# PackingTrackerApp

Aplicación Android para computadoras móviles de almacén. El primer equipo previsto es el Honeywell CK65. Va a consumir la API de [packingTracker](../packingTracker).

Abre esta carpeta en Android Studio y sincroniza Gradle. El módulo `app` es una actividad en blanco.

- `minSdk` 26 (Android 8.0), la primera versión del CK65.
- `compileSdk` 36.1, la plataforma Android instalada en este equipo.
